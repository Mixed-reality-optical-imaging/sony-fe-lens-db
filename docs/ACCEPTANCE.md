# 验收记录

日期：2026-09-22。环境：Windows、Node 22.22.1、npm 10.9.4、Codex 内置浏览器。实际界面验收以生产构建的本地 HTTP 预览为主；开发服务器另行检查热更新。

## 构建与自动化

- `npm run validate:data`：通过。286 款、13 品牌，全部记录满足卡口、画幅、来源及日期要求；158 款主要规格齐全，128 款部分参数缺失；6 条人民币价格均可追溯。
- `npm test`：15 项测试通过。覆盖中英文与别名搜索、焦段边界、类别交并集、变光圈、未知值排序、价格边界、快捷规则、URL 往返、损坏偏好恢复和数据回归。
- 1200 条记录、50 轮组合查询，当前电脑单轮平均约 5 ms，测试阈值 100 ms。此为本机纯查询逻辑测试，不是不同设备的性能承诺。
- `npm run build`：通过 TypeScript 和生产构建；应用、依赖、静态数据分块，无超过 500 kB 的单个构建块。
- 依赖审计：安装时 npm 报告 0 项已知漏洞。

## 核验时修正的问题

- `35mm` 的子串匹配曾包含 `135mm`，已将独立焦距和光圈关键词按数值精确匹配。
- 索尼 STF 的 T5.6 不作为 F 光圈另一端，近摄数值不再误读说明中的对焦环刻度；AF/MF 取最短距离并保留原文备注。
- 适马的光学结构存在“片 / 组”和“组 / 片”两种顺序，已按字段名称核对，并增加组数不能大于镜片数的校验。
- 老蛙地区站未标明单位的近摄距离和存在矛盾的尺寸不予采用。
- 抽屉卸载时先关闭原生 dialog，再恢复焦点。
- React 根入口与页面组件分离，避免热更新重复创建根；可选查询工具的中止不再产生未处理的 Promise 拒绝。
